2. Context
Component Diagram:
This IoT application listens for incoming MQTT sensor messages and displays them in real time
inside the Android UI.
It uses:
• MQTT (Eclipse Paho) for sensor communication
• Room Database for storing incoming sensor values
• Android TextViews for live output of acceleration, gyro, magnet, and time
• Douglas-Peuker algorithm for data reduction

5.1.1. Running on an Emulator (Android Studio)
• No network setup required.
• The app automatically uses:
tcp://10.0.2.2:1883
• Because the emulator cannot access your PC directly — 10.0.2.2 is the gateway.
• MQTT will work immediately if Mosquitto is running on your PC.
5.1.2. Running on a Real Physical Phone
Requirements:
1. Mosquitto must be running on your PC
2. Port 1883 must be open
3. Phone and PC must be on the same Wi-Fi
4. Correct LAN IP set in PHONE_BROKER
5. No VPN, guest network, or firewall blocking
After launching the app: * It will connect to the broker * Subscribe to sensor topics * Publish test
messages * Display incoming sensor data * Save it to the local Room database
If connection fails, you will see a Toast:
"MQTT error: ..."
And the log may show:
SocketTimeoutException: failed to connect
This always indicates a network/firewall/IP mismatch.
6. Quality & Constraints
Goal Strategy
Performance (Data Ingestion) Use DB.databaseWriteExecutor to ensure high￾frequency sensor data insertion happens off the
main thread, preventing UI freezes.
12Performance (Filtering) Database queries are optimized using WHERE
clauses on the indexed timestamp column.
Dynamic observer management prevents
conflicting asynchronous updates.
Usability (Reactivity) LiveData ensures charts and data streams
update automatically and smoothly, reducing
perceived latency for the user.
Usability (Consistency) BaseChartActivity and DatePickerHandler
enforce consistent styling and interaction across
the application’s filtering interface.
1. Tech Stack Dependence: Strong dependency on Android OS, Java, AndroidX libraries (Room,
LiveData), and the external MPAndroidChart library.
2. Hardware Dependency: The core function of the app requires an Android device.
